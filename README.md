# La Pipa · Catálogo europeo de tabacos de pipa

Proyecto web estático para documentar tabacos de pipa, sus perfiles y reseñas, con especial atención a la disponibilidad en mercados europeos.

## Principios del proyecto

- Las imágenes de la web son recursos propios almacenados en `assets/images/`; no se cargan imágenes remotas.
- Las reseñas de terceros se utilizan como fuentes para elaborar síntesis editoriales propias; no se copian masivamente textos protegidos.
- La disponibilidad se tratará por país y se marcará como verificada, no verificada o histórica cuando corresponda.
- La base distinguirá datos objetivos, valoración de comunidad y síntesis editorial.
- El contenido es informativo. El tabaco contiene nicotina y es adictivo y perjudicial para la salud.

## Estructura

- `index.html` — portada y buscador.
- `styles.css` — diseño responsive.
- `app.js` — interfaz y filtros.
- `data/catalogo.json` — esquema de la futura base de datos.
- `assets/images/` — ilustraciones locales originales.

## Fuentes de investigación

La investigación combina fuentes comunitarias de reseñas con fuentes oficiales europeas. TobaccoReviews declara una base de más de 8.500 tabacos y más de 106.000 reseñas en septiembre de 2026. La Comisión Europea explica que fabricantes e importadores deben notificar información de productos a los Estados miembros mediante EU-CEG y que la normativa europea regula también el tabaco de pipa.

La disponibilidad europea no se inferirá únicamente de una base mundial: se verificará por mercado cuando sea posible.
