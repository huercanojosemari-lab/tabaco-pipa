Qué datos se tratan

La consulta pública del catálogo no requiere cuenta. Si una persona crea una cuenta o se suscribe a la newsletter, pueden tratarse los datos que aporte, como correo electrónico, nombre y datos de perfil necesarios para la prestación solicitada.

Finalidades y base jurídica

Los datos de cuenta se utilizan para gestionar autenticación y funciones de usuario. Los datos de newsletter se utilizan para gestionar la suscripción solicitada. Cuando la base jurídica sea el consentimiento, este debe ser una acción afirmativa, libre, informada y revocable.

Proveedores

La web se publica mediante GitHub Pages y utiliza Supabase para autenticación y gestión de suscripciones. La configuración pública del cliente no contiene claves secretas. Las condiciones concretas de tratamiento y, cuando proceda, las transferencias internacionales deben revisarse con la configuración contractual efectiva de estos proveedores.

Conservación y derechos

Los datos se conservarán durante el tiempo necesario para la finalidad correspondiente y mientras exista una obligación legal que lo requiera. La persona interesada puede solicitar acceso, rectificación, supresión, oposición, limitación o portabilidad cuando sean aplicables, además de retirar el consentimiento cuando esa sea la base jurídica.

Para ejercer derechos: [PENDIENTE: correo de privacidad].

Seguridad

Se aplicarán medidas técnicas y organizativas adecuadas al tratamiento. Las políticas de acceso de Supabase deben impedir que una persona usuaria pueda consultar datos privados de otras personas.
